# ScholarFlow 任务式入门与使用记录更新

更新日期：2026-11-10。正式前端仍使用 GitHub Pages；现有 Dify、DeepSeek、共享数据库与原件存储保持原连接。

## 从一次真实任务开始

进入已有资料的工作区后，主按钮是 **Start revising this lecture**。它带学习者选择来自当前学习包的问题、写自己的解释、提交反馈、打开原文核查，并手写和保存修正后的理解。引导不会自动填写答案或运行模型。其他工具和共享目标保留为可选入口。新手高亮导览共七步，围绕这一次任务展开；完成导览后进入实际练习。

## 记录真实使用体验

资料工作区的 **Record this study session** 接受实际日期、贡献者、具体任务、可选的人工基线及操作、系统等待、检查、修正时间，以及用户亲自填写的问题、修改和是否复用旧成果。未测量的时间保留为 null，不推定为零，不自动计算没有依据的节省率。

未提交记录按资料保存在当前浏览器。明确保存后，每条使用记录作为独立共享记录写入现有 history 存储，避免把两位组员的新增记录放在同一个来源数组里互相覆盖。该记录与模型练习分开展示，也不会计入模型运行次数。支持事实记录 JSON 导出。

## 定向刷新缓存

**Share group → Refresh display cache** 重新打开当前版本，清除派生的结果显示索引、暂存的接续指向和旧导览完成标记，随后从现有小组接口重新读取共享资料。它保留原始文件、资料、完成历史、未提交草稿和待同步写入；不清除登录、其他网站数据或整个 localStorage。正在上传或运行模型时，先完成当前操作再刷新。

发布链接可带 `refresh-view=1&release=20261110-study-guide` 执行这次定向刷新。页面执行后会移除 refresh-view 参数，保留当前小组 room。

## 页码定位修正

旧流程在每个处理分段内判断摘录是否唯一。真实金融课件的 C014 原文同时出现在物理 PDF 第33和36页，由于跨分段，旧结果仅显示36页。

现在在所有分段合并后，对整份来源的页映射重新匹配。保有完整提取文字和页映射的旧学习包也会自动复核。多处匹配保留 candidate_pages，并显示候选页，不能声称唯一定位。无需新增模型调用。

原金融实测原始 JSON 和录像保持历史原样；审阅更正为：19条摘录均存在，15条具有单一物理页候选，4条具有多个物理页候选。它们仍不能证明解释准确性或知识点覆盖率。

## 自动化边界

网页上传仍需要页面保持打开；已知引用字段与缺失状态继续保留。拥有者 Google Drive 定时归档仍是独立通道，没有在这次更新中写入小组资料链。使用记录和修正后的理解由学生亲自填写，产品不生成最终报告的核心分析。

## 本轮验证范围

14项处理与共享存储测试通过；36项隔离浏览器行为验证通过，页面JavaScript错误为0。覆盖真实金融原文的全文件候选页、任务引导、问题选择保留、手写修订、使用记录共享与本地草稿、未测时间、导出、手机布局、定向刷新保留待同步写入及历史来源已删除的情况。网页测试只使用一次模拟模型响应，没有新增模型计费，没有向公开小组写入测试记录。此结论不代表已完成学生数日体验或学习效果实验。
