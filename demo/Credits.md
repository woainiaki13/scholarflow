# ScholarFlow product films — credits

The current 120-second product keynote was created with OpenMontage using a bespoke Remotion composition. The earlier 54-second OpenMontage and 44-second video-shotcraft films remain available. All use actual ScholarFlow website captures, retained finance-course outputs and the original course PDF supplied for the demonstration. Motion, camera moves and transitions are edited product presentation.

## Concept renderings in the new keynote

Three purpose-made images were generated with OpenAI’s built-in `image_gen.imagegen` tool, then animated and composited in Remotion: paper through a lilac prism into three learning objects; source-to-quotation optical macro; and a shared learning plane. These are original visual metaphors, not actual hardware, screenshots or generated examples of model answers. The tool does not expose a model identifier. Native image dimensions are 1672 × 941.

The keynote uses real retained outputs from all eight tools on the deployed GitHub website with the finance source.
